NOTES

        
実行前に知っておくこと

        

          

            
ブラウザは実行しません

            
生成されるのはただのテキストです。実際の reg / sc / schtasks は、ダウンロードした .bat をあなたが実行したときだけ動きます。

          

          

            
UAC で管理者になる

            
スクリプト先頭で net session を試し、失敗したら PowerShell の Start-Process -Verb RunAs で自分自身を昇格します。

          

          

            
戻せるようにしてある

            
同じ項目の逆操作を「復元」モードで書き出せます。Windows Update は推奨セットに含めていません。

HOW TO USE

            
使い方

          

          
        

        
    
          
  1. 01
    項目を選ぶ
    推奨プリセットのままでも、個別にオンオフしても構いません。赤い「危険」ラベルは Windows Update など副作用の大きい項目です。
    2. 
          
  2. 02
    .bat をダウンロード
    「遮断 .bat」を保存します。UTF-8（BOM 付き）で書き出されるので、日本語メッセージも崩れません。
    3. 
          
  3. 03
    ダブルクリックで実行
    スクリプトが自分自身を管理者として再起動します。UAC で「はい」を選べば、管理者権限でコマンドが走ります。
    4. 
          
  4. 04
    再起動して完了
    終了時に再起動を尋ねます。DiagTrack や Autologger は再起動後に完全反映されます。戻したくなったら復元 .bat を使います。
    5. 
        

        

          このサイトはコマンドをあなたの PC 上では実行しません。生成された .bat はローカルの cmd.exe で動きます。社用 PC ではポリシーで一部が拒否されることがあります。
